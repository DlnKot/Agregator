# Remote Desktop Manager

Агрегатор для запуска клиентов подключения к удалённым рабочим столам (RDP, VMware Horizon, Citrix Workspace).

## Возможности

- **Подключения** — управление списком подключений к удалённым рабочим столам
- **Профили** — группировка подключений в профили для быстрого запуска
- **Настройки** — конфигурация параметров для каждого типа подключения:
  - RDP: разрешение, глубина цвета, несколько мониторов, буфер обмена, перенаправление устройств
  - VMware Horizon: URL Broker, Desktop Pool, дополнительные опции
  - Citrix Workspace: Store URL, режим HDX, дополнительные параметры
- **Проверка сети** — диагностика доступности удалённых сервисов с оценкой качества соединения
- **Раздел помощи** — инструкции по настройке и использованию (HelpDesk, Indeed, виды удалёнки, чат-бот)
- **Автообновление** — автоматическая проверка и установка обновлений приложения
- **Метрики** — сбор анонимной статистики использования для улучшения продукта

## Использование

### Первый запуск
При первом запуске приложения необходимо ввести домен и имя пользователя для корректной работы подключений.

### Добавление подключения
1. Нажмите кнопку "Добавить" в разделе "Подключения"
2. Выберите тип подключения (RDP, Horizon, Citrix)
3. Заполните название и хост (IP или hostname)
4. При необходимости настройте дополнительные параметры

### Запуск подключения
- Нажмите кнопку воспроизведения на карточке подключения
- Клиент запускается с учётом ОС:
  - **RDP**: Windows → `mstsc.exe`, macOS → `Windows App`
  - **Horizon**: Windows → `vmware-view.exe`, macOS → `VMware Horizon Client`
  - **Citrix**: Windows → `selfservice.exe`, macOS → `Citrix Workspace`

### Проверка сети
- Перейдите в раздел "Проверка сети"
- Нажмите "Проверить все" для диагностики всех сервисов
- Оцените результаты: время отклика, потери пакетов, рекомендации

### Настройки
- Перейдите в раздел "Настройки"
- Настройте параметры по умолчанию для каждого типа подключения
- Нажмите "Сохранить"

## Конфигурация

### Файл развёртывания (deployment-defaults.json)

Для корпоративного развёртывания можно использовать файл `config/deployment-defaults.json`:

```json
{
  "settings": { ... },
  "connections": [ ... ],
  "profiles": [ ... ]
}
```

### Метрики

Приложение собирает анонимную статистику использования:
- Запуск и закрытие приложения
- Запуск подключений (RDP, Horizon, Citrix, VPN)
- Использование разделов (подключения, настройки, проверка сети, помощь)
- Ошибки и исключения

Данные хранятся локально и могут быть отправлены на сервер для анализа. Отправка метрик отключена по умолчанию.

## Требования

- Node.js 18+
- Electron 33+
- Windows или macOS
- Для macOS:
  - RDP: установлен `Windows App` (или `Microsoft Remote Desktop`)
  - Horizon: установлен `VMware Horizon Client`
  - Citrix: установлен `Citrix Workspace`
